# 👨‍🔬 个人学术主页

简洁的学术简历式个人主页，适合求学申请使用。

## 页面结构

- **个人信息** — 姓名、学校、研究兴趣、联系方式
- **论文成果** — 按时间倒序排列的发表列表
- **研究经历** — 科研项目简介
- **荣誉获奖** — 奖学金、竞赛奖项等

## 修改指南

打开 `index.html`，搜索 `★` 标记的位置替换为你的真实信息。

主要修改点：
1. 姓名、学校、GPA、研究方向
2. 邮箱、GitHub 链接
3. 论文列表（标题、作者、会议/期刊）
4. 研究项目
5. 荣誉奖项
6. 简历 PDF 下载链接

## 技术栈

纯 HTML + CSS + JS，零依赖，响应式设计，支持暗色模式。
