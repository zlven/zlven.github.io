简介

我目前就读于 四川大学 软件工程专业（2023 级本科），研究方向主要为 生成模型 与 扩散模型，特别是离散扩散模型在文本生成中的应用。 我热衷于探索生成式人工智能的前沿方向，并致力于将理论成果转化为开源实践。

以共同作者身份在 ACM Multimedia (MM) 上发表论文 "BRACE: Taming Sharp Irregularities via Barycentric Rational Forecasting for Fast Diffusion Transformers Inference"，关注扩散模型推理加速。 同时在 GitHub 上维护了 SEDD-LaTeX-RLHF 开源项目。未来希望能在生成模型领域继续深造， 攻读硕士或博士学位，做出有影响力的研究工作。

开源项目

SEDD-LaTeX-RLHF · 离散扩散模型 + RLHF 生成 LaTeX 数学公式

将离散扩散模型（SEDD）与强化学习（PPO）结合，通过 RLHF 对齐 生成高质量 LaTeX 数学公式。项目实现了完整的 SFT → RLHF 流程， 包括基于 S1K-1.1 数据集的监督微调、自定义多维奖励函数 （语法正确性、数学内容质量、探索奖励等），以及基于 PPO 的对齐训练。 针对 GPT-2 大词表场景做了稀疏优化，单卡 GPU 即可训练。
